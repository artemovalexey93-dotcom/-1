== Description ==

Aster Cleaning Service Theme provides a structured layout for presenting cleaning services, company information, contact details, and other relevant website content. The design includes sections for service descriptions, images, introductory information, and calls to action. Cleaning companies can use dedicated sections to explain their available services, pricing information, and operating details. The layout can also present house cleaning services through organized content blocks with supporting images and descriptions. For commercial cleaning companies, the theme provides space to outline service options, business information, and contact details. Residential cleaning businesses can use similar sections to describe home- focused services and provide inquiry information. The responsive design allows pages to adjust across desktop, tablet, and mobile screen sizes. Customizable elements can be used to modify text, images, colors, menus, and other visual components according to website requirements. Navigation menus help organize important pages, while contact sections can display phone numbers, email addresses, locations, and inquiry forms. Additional sections can be used for testimonials, service details, announcements, or other informational content, depending on the website’s content structure and configuration.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
